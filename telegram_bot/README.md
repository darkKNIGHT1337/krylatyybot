# Telegram Bot — Приветственный бот с видео-контентом

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка бота

Открой файл `bot.py` и заполни блок **КОНФИГУРАЦИЯ** (в самом начале файла):

| Переменная | Что вставить |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `MAIN_CHANNEL_ID` | ID канала вида `-100XXXXXXXXXX` |
| `REVIEWS_LINK` | Ссылка на канал с отзывами |
| `ADMIN_LINK` | Ссылка на личный аккаунт |

### 3. Добавить видео-файлы

Создай папку `videos/` рядом с `bot.py` и положи туда:

```
videos/
    greeting_note.mp4       ← видео-кружочек (квадратное, до 1 мин)
    private_channel.mp4     ← видео для «Приватный канал»
    copytrading.mp4         ← видео для «Копитрейдинг»
    free_lesson.mp4         ← видео для «Бесплатный видео-урок»
```

**Или** получи `file_id` и вставь в переменные (быстрее):
1. Запусти бота
2. Отправь видео/кружочек прямо боту в личку
3. Бот ответит `file_id` — скопируй и вставь в `bot.py`

### 4. Добавить бота в канал

- Зайди в настройки канала → Администраторы
- Добавь бота как администратора
- Дай право «Добавление участников» (Add Members)

### 5. Запуск

```bash
python bot.py
```

## Структура файла bot.py

```
КОНФИГУРАЦИЯ       — токен, ID канала, ссылки, пути к видео
СОСТОЯНИЯ FSM      — MAIN_MENU, VIEWING_VIDEO
КЛАВИАТУРЫ         — главное меню (5 кнопок), кнопка «Назад»
ВСПОМОГАТЕЛЬНЫЕ    — show_main_menu(), send_section_video()
ХЭНДЛЕРЫ           — /start, chat_member, кнопки, file_id-хелпер
ТОЧКА ВХОДА        — main()
```

## Важные замечания

1. **Первый /start обязателен** — Telegram не разрешает боту писать пользователю в личку, пока тот сам не написал боту хотя бы один раз. Попроси подписчиков сначала нажать `/start` у бота.

2. **MemoryStorage** — состояния FSM хранятся в памяти. При перезапуске бота сбрасываются. Для продакшена можно заменить на `RedisStorage`.

3. **file_id** — после первой загрузки видео Telegram выдаёт `file_id`. Сохрани его в переменную, чтобы повторные отправки шли мгновенно без загрузки файла.

## Troubleshooting

| Проблема | Решение |
|---|---|
| Бот не реагирует на подписку | Убедись, что бот — администратор канала |
| Ошибка `Forbidden: bot can't initiate conversation` | Пользователь не нажимал /start в боте |
| Видео не отправляется | Проверь путь к файлу или вставь правильный `file_id` |
| Кружочек не работает | Видео должно быть квадратным MP4, до 1 минуты |
